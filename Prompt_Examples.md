# Agents Are Bidirectional

## Pattern 1: Role + (Context + Task + Examples)

You are a senior software engineer.

You must setup a .NET 10 application. Create a folder in this repository called "ApprovalChainApp".

- You must create an empty Xunit project with Fakeiteasy package.
- You must create an empty console application project. This project reference  the unit test project.


## Pattern 2: Role + (Context + Task + Examples) + Iterative Feedback Loop (“Ask-back” for clarification and refinement)

You are a senior project owner.

You must create an specification file for "ApprovalChainApp". The spec file must contains the functional and non-functional requirements for an approval process to buy office material in a company.

Ask me questions to define together all aspects of the application. When you ask me questions, do it one by one. Always include your own recommendation. Try to be direct own your questions.
